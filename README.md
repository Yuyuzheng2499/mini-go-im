# mini-go-im

基于 Go TCP Socket 实现的轻量级即时通信系统。项目用于学习 Go 网络编程、goroutine 并发模型、channel 消息分发以及基础 IM 业务流程。

## 功能特性

- TCP 服务端监听客户端连接
- goroutine-per-connection 并发处理模型
- 用户上线、下线管理
- 在线用户列表维护
- 公聊消息广播
- 私聊消息发送
- 用户名修改
- 客户端菜单式交互
- 客户端支持通过命令行参数指定服务端 IP 和端口
- 服务端命令测试覆盖，包括 `/who`、`/rename`、`/to` 和广播逻辑

## 技术栈

- Go
- net/TCP
- goroutine
- channel
- sync.RWMutex
- Go testing

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/Yuyuzheng2499/mini-go-im.git
cd mini-go-im
```

### 2. 启动服务端

```bash
go run ./cmd/server
```

服务端默认监听：

```text
127.0.0.1:8888
```

### 3. 启动客户端

新开一个终端执行：

```bash
go run ./cmd/client
```

客户端默认连接：

```text
127.0.0.1:8888
```

也可以通过参数指定服务端地址：

```bash
go run ./cmd/client -ip 127.0.0.1 -port 8888
```

如果要测试多用户聊天，可以多开几个终端分别启动客户端。

## 客户端使用说明

客户端启动后会显示菜单：

```text
1. 公聊模式
2. 私聊模式
3. 更新用户名
0. 退出
```

### 公聊模式

选择：

```text
1
```

然后输入聊天内容，消息会广播给所有在线用户。

输入：

```text
exit
```

退出公聊模式，回到主菜单。

### 私聊模式

选择：

```text
2
```

客户端会先向服务端查询在线用户列表，然后提示输入私聊对象用户名和消息内容。

私聊消息只会发送给指定用户，不会广播给所有人。

### 更新用户名

选择：

```text
3
```

然后输入新的用户名。客户端会向服务端发送改名命令，服务端修改成功后返回：

```text
用户名已修改为：新用户名
```

### 退出客户端

选择：

```text
0
```

客户端退出。

## 服务端协议说明

客户端和服务端之间基于文本命令通信。

| 命令 | 说明 | 示例 |
| --- | --- | --- |
| 普通文本 | 公聊广播 | `hello` |
| `/who` | 查询在线用户 | `/who` |
| `/rename <用户名>` | 修改当前用户名称 | `/rename 张三` |
| `/to <用户名> <消息>` | 给指定用户发送私聊消息 | `/to 张三 你好` |

服务端会根据消息内容判断命令类型：

- `/who`：只返回给当前用户
- `/rename`：修改当前用户名称
- `/to`：发送给指定用户
- 其他内容：作为公聊消息广播

## 测试

项目测试代码集中放在根目录 `test/` 目录中。

运行全部测试：

```bash
go test ./...
```

不使用缓存重新运行：

```bash
go test ./... -count=1
```

只运行测试目录：

```bash
go test ./test -count=1
```

带超时时间运行，避免阻塞测试长时间挂起：

```bash
go test ./... -count=1 -timeout=5s
```

当前测试覆盖：

- `/who` 查询在线用户
- `/rename` 修改用户名
- `/rename` 用户名重复提示
- `/to` 私聊消息发送
- 私聊消息保留空格
- 私聊异常输入提示
- 普通消息广播
- `ListenMessages` 从用户 channel 写入连接

## 手动测试建议

可以使用三个终端进行手动测试。

终端 1 启动服务端：

```bash
go run ./cmd/server
```

终端 2 启动客户端 A：

```bash
go run ./cmd/client
```

终端 3 启动客户端 B：

```bash
go run ./cmd/client
```

建议测试流程：

1. 客户端 A 选择 `3`，修改用户名为 `张三`
2. 客户端 B 选择 `3`，修改用户名为 `李四`
3. 客户端 A 选择 `1`，发送公聊消息
4. 客户端 B 检查是否收到公聊消息
5. 客户端 A 选择 `2`，向 `李四` 发送私聊消息
6. 客户端 B 检查是否收到私聊消息
7. 任意客户端选择 `0` 退出

- 支持查询在线用户
- 支持修改用户名
- 客户端支持通过 `-ip`、`-port` 指定服务端地址
- 新增根目录 `test/` 测试包，覆盖服务端核心命令逻辑
